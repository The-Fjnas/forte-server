# RFs  Requisitos Funcionais
- O usuario deve receber um codigo de verificacao no email para validar o codigo
- O codigo deve ser somente 4 caracteres
- O codigo dever ser somente numerico

# RNFs Requisitos nao Funcionais
- Apos autenticar, deve ser usar criptografia JWT
- Apos cadastrar, usar o bcriptjs para criptografar a senha
